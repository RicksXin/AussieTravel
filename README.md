# 澳游 · Aussie Days

Taro 4.2.1 + React 18 的微信小程序，同时支持 H5 预览。使用用户的「2026 十一澳洲」飞书表格，覆盖 2026-09-25 至 2026-10-03。

只设计移动端：单列页面、底部四项导航、横向日期选择及底部详情面板。电脑浏览器也保持最大 430px 的手机宽度，没有桌面侧栏或 PC 布局。

## 开始使用

推荐 Node.js 22/24。已提供 npm 锁文件；Taro 的可选跨平台 peer 依赖通过 legacy peer 模式安装。

```sh
npm ci --legacy-peer-deps
npm run dev:weapp
```

在微信开发者工具中导入本项目根目录。`project.config.json` 的 `miniprogramRoot` 指向 `dist/weapp/`，已配置 AppID `wx1784519777e674b5`。使用具有该小程序开发权限的微信账号登录后，可进行真机预览。不要在客户端配置 AppSecret。

也可以直接导入 `dist/weapp/`。如果已经导入了 `dist/`，该目录下的 `project.config.json` 必须包含 `"miniprogramRoot": "weapp/"`，否则会报“在项目根目录未找到 app.json”。推荐导入项目根目录，避免清理构建目录后丢失开发者工具配置。

```sh
npm run build:weapp  # 微信生产构建
npm run dev         # H5 开发预览，端口 10086
npm run build:h5    # H5 生产构建，dist/h5
npm test           # 时间、提醒、日历与导入完整性测试
```

## 功能

- 每日时间轴：分类与搜索、查看详情、标记完成、修改或清除时间、恢复原计划时间。
- 旅途全览：按日期查看墨尔本、悉尼、大洋路和 Kiama 行程。
- 行前清单：原表提取的 88 项准备、背包与行李事项，进度本地保存。
- 原计划随身看：保留详细表各天的文字备注，包含菜单、备选、预订信息、交通与摄影攻略。
- 核对事项：酒店不一致、企鹅与晚餐冲突、未定行程、渡轮班次等。
- 位置：H5 打开 Google Maps 地名搜索；微信复制地名并提示在地图搜索。原数据没有已验证坐标，未擅自调用 `openLocation`。
- 日历：H5 下载 `.ics`；微信生成本地 `.ics` 并调用文件分享，需在真机测试。导入手机日历后由系统提醒，提前 30 分钟。仅导出已安排时间、非备选事项。日历中的事件时长用 30 分钟占位，实际游玩时长看原计划。
- 应用内提醒：页面处于前台时，每 30 秒检查即将开始的事项。关闭或切后台后不保证提醒。

## 微信订阅消息

尚未接入，界面明确显示此状态。可靠的离线微信提醒还需要：

1. 真实小程序 AppID，以及后台申请通过的订阅消息模板。
2. 用户主动点击订阅，通过 `Taro.requestSubscribeMessage` 获取授权。
3. 服务端通过 `wx.login` 的 code 获取用户身份，保存经用户授权的行程时间。
4. 服务端定时任务与订阅消息发送接口，并处理授权次数、去重、修改/取消行程及发送失败。

当前没有云端数据上传、登录、推送后端或订阅授权按钮，不会显示虚假的“已订阅”。无需这些配置即可浏览与管理行程。

## 数据与目录

- `src/data.js`：整理后的每日活动及待核对事项，保留原表行号。
- `data/detail.json` / `data/summary.json`：飞书读取快照（修订号 590，2026-09-16）。
- `data/trip-notes.json`：完整读取 454 行后提取的非空文字备注和准备清单。
- `scripts/import-source.mjs`：由以上两份 CSV JSON 快照重新生成备注数据，校验是否截断。
- `src/logic.js`：日期、下一项安排、ICS 生成，独立于平台。
- `src/services.js`：Taro 存储、剪贴板、日历文件和多端适配。
- `src/pages/index/index.jsx`：React 页面与四个主视图。
- `src/assets`：内置插画、图标与 SVG 源文件，无在线图片、字体依赖。

行程文字与图片随小程序内置；完成状态和自定时间保存在当前设备，不自动跨设备同步。微信小程序版本仍需联网首次加载，地图和外部飞书链接也需要网络。

飞书表格不会自动同步，修改原表后需重新读取并重新整理 `src/data.js`。价格、日落、营业时间、预订与取消条款只是原表笔记，未再次核实；浮动图片没有导入。源数据含私人预订信息，请将此项目作为私人行程使用。

当前旅行日期位于澳洲夏令时切换前，上海/吉隆坡 +08:00，墨尔本/悉尼 +10:00。无 Intl 环境的日期回退仅适用于本次行程日期；拓展其他季节前需更新时区方案。
