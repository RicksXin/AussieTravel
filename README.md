# 澳游 · Aussie Days

Taro 4.2.1 + React 18 的微信小程序，同时支持 H5 预览。使用用户的「2026 十一澳洲」飞书表格，覆盖 2026-09-25 至 2026-10-03。

只设计移动端：单列页面、底部四项导航、横向日期选择及底部详情面板。电脑浏览器也保持最大 430px 的手机宽度，没有桌面侧栏或 PC 布局。

## 开始使用

推荐 Node.js 22/24。已提供 npm 锁文件；Taro 的可选跨平台 peer 依赖通过 legacy peer 模式安装。

```sh
npm ci --legacy-peer-deps
npm run dev:weapp
```

在微信开发者工具中导入本项目根目录。`project.config.json` 的 `miniprogramRoot` 指向 `dist/weapp/`，已配置 AppID `wx1784519777e674b5`。使用具有该小程序开发权限的微信账号登录后，可进行真机预览。不要在客户端配置 AppSecret。

也可以直接导入 `dist/weapp/`。如果已经导入了 `dist/`，该目录下的 `project.config.json` 必须包含 `"miniprogramRoot": "weapp/"`，否则会报“在项目根目录未找到 app.json”。推荐导入项目根目录，避免清理构建目录后丢失开发者工具配置。

```sh
npm run build:weapp  # 微信生产构建
npm run dev         # H5 开发预览，端口 10086
npm run build:h5    # H5 生产构建，dist/h5
npm test           # 时间、提醒、日历与导入完整性测试
```

## 功能

- 每日时间轴：分类与搜索、查看详情、标记完成。
- 旅途全览：按日期查看墨尔本、悉尼、大洋路和 Kiama 行程。
- 行前清单：原表提取的 88 项准备、背包与行李事项，进度本地保存。
- 原计划随身看：保留详细表各天的文字备注，包含菜单、备选、预订信息、交通与摄影攻略。
- 每晚超市补给：住酒店的每一天最后一项是酒店附近超市，备注按**次日行程**列出要买什么。9/25 在夜间航班上、10/3 当天回程，两天没有这一项。
- 核对事项：酒店不一致、企鹅与晚餐冲突、未定行程、渡轮班次等。
- 位置：已从用户的「9月26日」Google My Maps 地点图层导入 7 个澳洲地点标记，匹配当前 9/26 的 8 项安排（Max 已移至 9/27）；Lune 在咖啡行程详情中提供独立导航入口。微信对已匹配地点调用 `openLocation`，H5 打开 Google Maps 路线。未匹配地点可复制地名或 Google 路线链接；微信详情也可复制 Google 链接到浏览器打开。地图坐标来自用户标记，不代表已验证建筑入口或实时营业情况。
- 日历：H5 下载 `.ics`；微信生成本地 `.ics` 并调用文件分享，需在真机测试。导入手机日历后由系统提醒，提前 30 分钟。仅导出已安排时间、非备选、非参考草案事项。日历中的事件时长用 30 分钟占位，实际游玩时长看原计划。
- 应用内提醒：页面处于前台时，每 30 秒检查即将开始的事项。关闭或切后台后不保证提醒。

## 微信订阅消息

尚未接入，界面明确显示此状态。可靠的离线微信提醒还需要：

1. 真实小程序 AppID，以及后台申请通过的订阅消息模板。
2. 用户主动点击订阅，通过 `Taro.requestSubscribeMessage` 获取授权。
3. 服务端通过 `wx.login` 的 code 获取用户身份，保存经用户授权的行程时间。
4. 服务端定时任务与订阅消息发送接口，并处理授权次数、去重、修改/取消行程及发送失败。

当前没有云端数据上传、登录、推送后端或订阅授权按钮，不会显示虚假的“已订阅”。无需这些配置即可浏览与管理行程。

## 数据与目录

- `src/data.js`：整理后的每日活动及待核对事项，保留原表行号。
- `data/detail.json` / `data/summary.json`：飞书读取快照（修订号 946，2026-09-21）。
- `data/source.json`：同步版本、完整读取范围及工作表元数据。
- `data/attractions.json` / `data/routes.json`：景点库与路线表文字快照；22 个景点备选展示于旅途全览。
- `data/trip-notes.json`：完整读取 474 行后提取的非空文字备注和准备清单。
- `scripts/import-source.mjs`：由详细、汇总、景点库快照及同步清单重新生成备注数据，校验是否截断。
- `src/places.js` / `data/map-sep26.json`：地图地点匹配、原始坐标和来源记录；仅包含澳洲坐标，不可直接套用到中国境内地点。
- `src/logic.js`：日期、下一项安排、ICS 生成，独立于平台。
- `src/services.js`：Taro 存储、剪贴板、日历文件和多端适配。
- `src/pages/index/index.jsx`：React 页面与四个主视图。
- `src/assets`：内置插画、图标与 SVG 源文件，无在线图片、字体依赖。

行程文字与图片随小程序内置；完成状态和自定时间保存在当前设备，不自动跨设备同步。微信小程序版本仍需联网首次加载，地图和外部飞书链接也需要网络。

飞书表格不会自动同步，修改原表后需重新读取并重新整理 `src/data.js`。当前已同步修订 946：JQ516、MU562、My Fair Lady、更新后的酒店和餐饮预约；10/2 草案与团方参考时刻标为 tentative，不导出日历或触发提醒。未变事项保持原 ID，新增事项使用独立 ID，避免旧完成状态串到新安排。设备上的既有自定时间仍保留；详情弹层仅展示行程信息与备注。价格、日落、营业时间、预订与取消条款只是原表笔记，未再次核实；浮动图片没有导入。源数据含私人预订信息，请将此项目作为私人行程使用。

当前旅行日期位于澳洲夏令时切换前，上海/吉隆坡 +08:00，墨尔本/悉尼 +10:00。无 Intl 环境的日期回退仅适用于本次行程日期；拓展其他季节前需更新时区方案。

### 攻略图片与云存储

攻略配图共 45 张（用户 Excel 23 张、小红书 22 张）。放在主包会让主包到 2.2 MB、超过微信 2 MB 上限而无法上传，因此小程序端改从云存储读取，H5 继续使用随构建复制的图片。移出后主包 724 KB。45 张图已上传至环境 `cloud1-3gogmo2me540df61` 的 `guide-media/`，与本地逐个文件名对账一致。

该环境套餐不允许修改存储权限规则（`tcb storage rules update` 返回 `OperationDenied.FreePackageDenied`），实测无签名链接返回 403、带签名返回 200。因此不记录永久地址，改由小程序在运行时用 `wx.cloud.getTempFileURL` 解析 `cloud://` 文件 ID。

- `data/media-manifest.json`：云存储环境、目录、上传日期与 45 个文件的体积校验值。`access: private` 说明依赖签名链接。
- `src/media.js`：按平台解析图片地址。小程序端一次解析全部 45 个文件 ID（`getTempFileURL` 单次上限 50），文件 ID 形如 `cloud://<环境>.<存储桶>/<路径>`，缺少存储桶段会让全部图片静默解析失败。下载统一走 `wx.cloud.downloadFile` 再 `FileSystemManager.saveFile` 落地；二次访问用本地路径，签名过期也不影响已缓存的图。启动时校验缓存文件是否被系统清理，失效则重新下载。这样在澳洲漫游或景区没信号时，先前看过的图仍然可见。
- 放大预览：`previewImage` 会自行下载传入的地址，并且**受 downloadFile 合法域名限制**，直接传云存储签名链接只会显示黑屏加转圈。因此点击放大时先用 `previewSrcList()` 把该组图片全部落地，只把本地路径交给 `previewImage`；期间显示「打开图片」加载提示。非云存储路径（如随包图片）原样透传。
- `src/app.jsx`：`onLaunch` 调用 `initCloud()` 初始化云开发并加载本地缓存索引。
- `scripts/upload-media.mjs`：上传图片、与云端列表对账、抽样校验签名链接可读后写入 manifest。

```sh
npx tcb login                        # 浏览器扫码授权，凭据存放于 ~/.config，不进仓库
npm run media:upload -- --dry-run    # 只检查登录状态
npm run media:upload                 # 上传、对账、抽样校验、写入 manifest
```

脚本会比对云端列表与 manifest，缺任何一个文件就拒绝写入 —— 静默的部分上传否则只会在真机上表现为某些详情页缺图。`scripts/import-guide-media.mjs` 新增图片后会清空 `uploadedAt`，提示需要重新上传。

这套方案不需要配置 downloadFile 合法域名（签名链接由云开发 SDK 下发），但小程序必须能初始化云开发。签名链接尚未解析完成时，图片位显示「图片加载中，无网络时只显示已看过的图」。H5 与行程浏览都不受影响。

环境到期时间显示为 2026-09-04，目前仍可上传与读取；续费或更换环境后若获得公开读权限，可改回固化永久地址的方案。
